# iPhone Deals voor Mama

Refurbished iPhone 17 Pro en 18 Pro deals (256 GB, topstaat, max € 1.100), met Swappie voorop.

- `index.html` – de pagina (geen build nodig).
- `data.json` – de deals. Wordt elke 6 uur automatisch bijgewerkt door een geplande taak.

Prijzen zijn wat de winkel liet zien op het moment van controle. Check altijd de site van de winkel voordat je koopt.
